## Quarantined file

`data/synthetic/_latent_traits_DO_NOT_USE_AS_FEATURES.parquet` holds the five
latent member traits that drive the simulation: health literacy, cost
sensitivity, digital engagement, contact propensity, persistence.

`JourneyStore` never loads this file. Two tests assert it is unreachable and that
none of its column names appears in the feature matrix. It exists only so the
generator's behaviour can be diagnosed.

## Event taxonomy

Twenty-eight event types across six groups: prescription lifecycle,
authorization lifecycle, claim lifecycle, cost, member contact, and
documents/outreach. See `domain/enums.py::EventType` — the enum is the
authoritative list, and this document does not duplicate it to avoid drift.

Three types constitute the ML label: `member_contacted_support`,
`case_escalated`, `rx_abandoned_at_counter`. `claim_rejected` is deliberately a
feature rather than a label — it is an operational precursor, not a
member-visible outcome.
